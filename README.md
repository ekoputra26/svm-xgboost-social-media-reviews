# svm-xgboost-social-media-reviews
Dataset and source code for SVM and XGBoost based sentiment analysis of Instagram, Facebook, and TikTok reviews.

# Social Media Sentiment Analysis Dataset
This repository contains the dataset and source code used in the study:

"Comparative Evaluation of Support Vector Machine (SVM) and XGBoost for Multi Platform Sentiment Analysis of Social Media Application Reviews"

## Contents

- Instagram review dataset
- Facebook review dataset
- TikTok review dataset
- Data preprocessing scripts
- Machine learning models (SVM and XGBoost)

## Purpose

The repository is provided to support reproducibility of the experiments reported in the manuscript.
